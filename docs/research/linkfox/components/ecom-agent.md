# LinkFox 跨境电商 Agent 工作台

目标入口：`https://os.linkfox.com/?from=home`。

本地入口：`/linkfox/ecom-agent`。

## 页面结构

- 80px 折叠式左侧导航，包含新任务、作图&视频、定时任务、店铺经营助手、资产、技能·专家、解决方案、学习中心和更多。
- 顶部状态栏，包含新版体验交流群、通知、免费得算力 0/5 和展开工作台。
- 网格背景和居中的标题“跨境电商AI运营助手”。
- 业务 Agent、图片、视频三种工作模式。
- 业务 Agent、图片、视频三种工作模式；业务 Agent 默认进入技能页签。
- 技能分类包括推荐、选品与开发、产品视觉、产品运营、营销广告、数据分析、通用/热点和合规检测。
- 默认技能卡包括 SIF 外观专利检测、亚马逊店铺报表、亚马逊广告报表、EchoTik 商品视频查询、1688 以图搜图和亚马逊前端商品搜索；专家页签提供选品分析、市场分析和 Listing 生成等任务卡。
- 任务输入框，包含添加素材、技能、提示词库、官方助手和发送按钮。
- 选择分组下拉菜单、客服/帮助浮动按钮和首次访问引导卡。

首页的“电商 Agent”和顶部“Agent”入口均指向这个本地页面。真实模型、账号、算力、资产和任务接口仍保持独立，当前页面提供可编辑的本地交互演示。
