# LinkFox `/home` 交互取证

## Tab 切换

- **自由创作**：提示“上传产品图，描述你想要的效果，让 AI 搞定所有设计”，操作为“添加”和“智能模式”，初始不可用的“去创作”。
- **套图 Agent**：提示“收到，开始套图设计之前，请提供商品图和卖点~”，出现“添加”“智能模式”和“智能品牌基因”选择。
- **视频 Agent**：提示“上传产品图，描述你想要的视频效果”，出现“添加”和“智能模式”。
- **链接复刻**：提示“先选择或上传商品图，再粘贴要完整复刻的 Amazon 商品链接”，出现“上传商品图”“更多建库方式”“40 算力/张”和禁用的“开始完整复刻并创建商品”。
- **电商 Agent**：是独立入口，不属于四个创作 tab；首页点击后打开跨境电商 AI 运营助手工作台。复刻项目提供本地 `/linkfox/ecom-agent` 页面，保留目标工作台的模式、技能、任务卡、输入区和分组交互。
- 四个创作 tab 使用本地状态切换；电商 Agent 和顶部 Agent 使用独立入口跳转。

## 工具卡片

- 主工具卡和小工具入口均为可点击按钮；点击后进入对应工具路径或触发本地演示反馈。
- 主卡片中的输入/输出缩略图和节日装饰是静态素材，不依赖实时接口。

## 灵感库

- 主滚动容器向下滚动后显示灵感库；默认 tab 是“当季热门”。
- 可切换“Agent 创作”“设计模板”“AI 作图工具”。
- 类型可切换“节日活动”“热门商品”；活动筛选展示万圣节、黑色星期五、圣诞节及倒计时。
- 图片卡悬停时显示原图标签与“做同款”按钮，点击按钮进入本地演示状态或对应工具入口。

## 弹层与浮动入口

- 首次进入目标站可能出现 LF 全能模型升级公告弹层；右上角关闭后恢复首页。
- 操作咨询和产品教程按钮固定在右侧；本地复刻保留按钮与视觉状态，真实客服/教程链接不接入。

## 响应式要求

- 桌面布局：顶栏、180px 侧栏、主滚动容器三段式布局。
- 小屏：侧栏收起为抽屉或隐藏，顶栏导航折叠，Agent tabs 与工具卡片允许横向滚动/单列堆叠，禁止页面横向溢出。
