# LingQi / 红熊 AI Replica

这是 `https://lingqi.redbearai.com` 的独立本地复刻项目。除登录页和 Agent 工作台外，已补齐本次已登录检查到的控制台、社交营销创建、任务、账号、聊天、评论、私信和会话设置入口。

## 本地启动

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 5203
```

打开：

- <http://127.0.0.1:5203/Login>
- <http://127.0.0.1:5203/agentworkbench>
- <http://127.0.0.1:5203/Console>
- <http://127.0.0.1:5203/app/Social/TrafficAddTask>

## 已复刻

- 浅蓝渐变登录背景、红熊 AI 标识和右侧登录卡片
- 红熊 AI、红熊灵通、红熊灵销、红熊灵智、Agent 互动服务平台、记忆熊六个产品切换
- 手机验证码登录和密码登录切换
- 验证码倒计时、协议勾选、校验提示
- 立即申请 AI 试用弹窗
- 本地演示登录后进入座席工作台
- 工作台左侧导航、顶部工具栏、Agent 卡片、会话输入和最近会话
- Console 控制台：用量卡片、推荐应用、平台应用页签、系统管理和快捷入口
- 社交营销：任务创建、社媒任务管理、社交账号管理、销售在线聊天、评论管理、私信管理、会话设置
- 社交页面的搜索、筛选、页签、账号展开、开关、发送和本地提示等交互

## 边界

目标站的真实登录态只用于浏览器核对。仓库不包含账号、验证码、Cookie、Token、真实 AI 模型、计费或生产接口；本地登录、任务提交、账号开关和消息发送均是可编辑的本地演示交互，不会向目标站写入数据。
