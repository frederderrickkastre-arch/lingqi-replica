# LingQi / 红熊 AI Replica

这是 `https://lingqi.redbearai.com` 的独立本地复刻项目。当前公开访问会跳转到 `/Login`，所以第一阶段先对齐登录页的 UI 和交互，并提供 `/agentworkbench` 的本地工作台入口，方便在拿到已登录页面后继续逐页校准。

## 本地启动

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 5203
```

打开：

- <http://127.0.0.1:5203/Login>
- <http://127.0.0.1:5203/agentworkbench>

## 已复刻

- 浅蓝渐变登录背景、红熊 AI 标识和右侧登录卡片
- 红熊 AI、红熊灵通、红熊灵销、红熊灵智、Agent 互动服务平台、记忆熊六个产品切换
- 手机验证码登录和密码登录切换
- 验证码倒计时、协议勾选、校验提示
- 立即申请 AI 试用弹窗
- 本地演示登录后进入座席工作台
- 工作台左侧导航、顶部工具栏、Agent 卡片、会话输入和最近会话

## 边界

目标站当前未登录访问会重定向到登录页。仓库不包含目标站账号、验证码、Token、真实 AI 模型、计费或生产接口；登录按钮仅创建本地演示会话。真实登录后的页面需要在目标站完成登录后再进行第二轮逐页复刻。
